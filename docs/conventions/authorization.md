# 권한 정책

이 문서는 대시보드 API와 화면에서 사용하는 역할별 접근 범위를 정의합니다.

## 역할

| 역할 | 설명 |
| --- | --- |
| `SUPER_ADMIN` | 사용자 계정, 관제 설정, 장비 제어와 테스트 기능을 관리하는 최고관리자 |
| `MANAGER` | 관제 현황을 조회하고 본인 계정 정보만 관리하는 일반 관리자 |

## API 권한표

| API 영역 | MANAGER | SUPER_ADMIN | 비고 |
| --- | --- | --- | --- |
| 로그인, 토큰 갱신, 로그아웃 | 가능 | 가능 | 로그인 전 공개 API |
| 내 정보 조회, WebSocket 접속 티켓 발급 | 가능 | 가능 | 본인 인증 필요 |
| 본인 이름·로그인 ID 수정, 비밀번호 변경 | 본인만 가능 | 본인만 가능 | 다른 사용자 수정 불가 |
| 대시보드 상태, 로그, 통계, 현장·구역·장비 조회 | 조회 가능 | 조회 가능 | 인증 필요 |
| 역주행 이력, 수신 상태, 최근 이벤트 조회 | 조회 가능 | 조회 가능 | 인증 필요 |
| 사용자 목록·상세 조회, 생성, 권한 변경, 비활성화 | 불가 | 가능 | 사용자 관리 기능 |
| 역주행 이벤트 상태 변경 | 불가 | 가능 | 처리 상태 변경은 최고관리자만 수행 |
| 통합제어보드 명령, 차단기·전광판 제어 | 불가 | 가능 | 실제 장비 제어 |
| 라이다 Mock, 테스트 스트림, 데모 API | 불가 | 가능 | 개발·검증용 기능 |
| 라이다 PC·통합제어보드 수신 API | 역할 인증 미적용 | 역할 인증 미적용 | 장비 연동 전용 경로, 별도 장비 인증 방식 검토 대상 |

## 구현 원칙

- 모든 사용자용 보호 API는 `authenticateToken`으로 로그인과 세션 버전을 검증합니다.
- 최고관리자 전용 API는 `authenticateToken` 다음에 `requireRole("SUPER_ADMIN")`를 적용합니다.
- 본인 정보 수정과 비밀번호 변경은 URL의 사용자 ID가 토큰의 사용자 ID와 같은지 서비스 계층에서 검사합니다.
- 프론트엔드는 역할에 맞지 않는 메뉴를 숨길 수 있지만, 실제 보안 검증은 반드시 백엔드에서 수행합니다.
