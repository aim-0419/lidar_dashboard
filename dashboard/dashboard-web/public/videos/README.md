로그인 배경 영상 파일은 아래 위치에 넣으면 됩니다.

파일명
- `login-background.mp4`

적용 위치
- `dashboard/dashboard-web/public/videos/login-background.mp4`

동작 방식
- 로그인 페이지에서 자동 재생됩니다.
- `loop`가 적용되어 무한 반복됩니다.
- `muted`, `playsInline` 상태로 재생됩니다.

권장 사항
- 16:9 비율
- mp4 형식
- 5초~8초 정도의 자연스러운 seamless loop 영상
- 중앙 로그인 박스가 잘 보이도록 너무 복잡하지 않은 배경
